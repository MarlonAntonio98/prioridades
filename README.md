# Prioridades

Tu matriz de Eisenhower: qué hacer ahora, qué planificar, qué delegar y qué eliminar.

## Publicarla

1. Crea un repositorio público llamado `prioridades` y sube todos estos archivos a la raíz.
2. En **Settings → Pages** elige la rama `main` y la carpeta `/ (root)`.
3. Abre en Chrome `https://tu-usuario.github.io/prioridades/` e instálala.

## Actualizar la app

Si cambias algún archivo, abre `sw.js` y sube el número de `VERSION` (por ejemplo, de `prioridades-v1` a `prioridades-v2`).
